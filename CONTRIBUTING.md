# Contributing

## Development flow

1. Fork the repository.
2. Create a branch from `main`.
3. Build the CLI locally.
4. Run `j2me --version` as a smoke test.
5. Open a pull request.

## Code style

- C++ 17.
- Prefer readable standard-library code.
- Keep workspace files out of the repository root.
- Keep bundled templates small and license-clean.
